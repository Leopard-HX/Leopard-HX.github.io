### Q6. 黑洞有哪些相变？按平坦 / AdS / dS 分类（标注是否需 Q/J）（2026-10-26）

**问题**：这不是追问，这是单独的问题——黑洞里面有哪些相变？按照时空是平坦、AdS、dS 分类，如果是需要带 Q/J 的需要单独标注，做成表格。

**解答**：

#### 0. 先统一口径

- **阶的判据**：一阶 = $G$ 连续而 $\partial G/\partial T$ 跳（有潜热）；二阶 = $C_Q$（或 $C_J$）发散 / 二阶导数跳；零阶 = $G$ **本身**跳。
- **"能不能有相变"取决于有没有可扫的旋钮**：$\Lambda$（扩展相空间的 $P$–$V$）、腔半径 $R$、电荷 $Q$、角动量 $J$、高阶曲率耦合、hair 参数、非线性 $\alpha$、额外紧致维。要出现"两个**稳定**黑洞相共存"，至少要有一支让 $C_Q>0$ 的旋钮，且两支能在某个参数点相遇。
- 平坦空间最容易"缺旋钮"：Schwarzschild 恒有 $C_Q=-8\pi M^2<0$；平坦 RN 的 $T(r_+)=\frac{1}{4\pi r_+}\left(1-\frac{Q^2}{r_+^2}\right)$ 虽非单调（$r_+=\sqrt3Q$ 处极大），但**小支 $C_Q<0$ 必须丢弃**，所以只剩一支稳定相、$G$–$T$ 不交叉。

### Q8. QNM 的具体计算流程是什么（扰动在哪 / 怎么取径向部分 / 得到的是什么）（2026-10-26）

**问题**：尝试概括 QNM 流程：考虑指定黑洞时空附近的标量场扰动（这个扰动发生在哪？近视界还是别处？标量场扰动对应的物理现象是什么？），取这个扰动的径向部分（怎么取？），考虑视界与无穷远的边界条件（可能还要分离变量）给出假设解带进方程化简，然后得到的是什么？

**解答**（全文见 `QNM与黑洞热力学/备注-QNM计算流程.md`）：骨架对，四处要改：

1. **「扰动发生在哪」不适用**。QNM 不是局部波包，而是整个外部区域上的**全局本征模**；只有扰幅包络偏好光子球（$\ell\ge1$ 时 $V$ 的峰在 $r\approx3M$）。“扰动”一词其实指**初始数据**，QNM 是把它展开后的本征基。
2. **「取径向部分」漏了两步**：① 因背景静态，先做 $e^{-i\omega t}$ 单频分解；② 径向函数必须**除以 $r$**（$R=u/r$），否则一阶导数项消不掉，拿不到薛定谔形式。
3. **「视界和无穷远」只对渐近平坦成立**：AdS 是**有限 $r_*$ 的 Dirichlet**（反射壁），dS 是**宇宙视界 outgoing**，York 腔是**壁上 BC**。
4. **「化简后得到什么」→ 复本征值问题，不是“解”**。得到的是 $u''+(\omega^2-V)u=0$（$r_*$ 坐标下），$V=f\left[\ell(\ell+1)/r^2+f'/r+\mu^2\right]$；边界条件含 $\omega$ 本身，所以只能数值找根，输出**离散复谱** $\{\omega_n\}$。

**另漏了第 0 步**：先线性化（test field，忽略反作用）。标量场在 `2606.29101` 那类文章里只是**温度计**（读法 (a) 玩具模型）；真观测对应的是 $s=2$ 引力扰动。

**三条坑**：QNM **不完备不正交**（非自伴，晚期是幂律尾）；本征值不含“可见性”（振幅/起振时在激发系数里）；符号约定（$e^{-i\omega t}$ 下 $\omega_I<0$ 稳定）必须自洽。

**回归主题**：相变 = 两族不同背景 = 两个不同 $V$ = 两套谱；“斜率跳变”几乎必然成立、**不构成证据**，真正有意义的是在**共存线**上比较。

2. **QNM 方程（正确形式）**：$u=e^{-i\Omega\zeta}\chi$（$\zeta'=1/f$）⇒ $f\chi''+(f'-2i\Omega)\chi'-[\ell(\ell+1)/\rho^2+f'/\rho]\chi=0$；视界 $\chi$ 解析，壁 $\chi(1)=0$。方程对 $\Omega$ **线性**。
3. **三个通过的预检**：热力学（机器精度）、平直腔代码校验（与 $n\pi/(1-a)$ 差 $2\times10^{-9}$）、小相打靶收敛（$\epsilon$ 变 100 倍只差 $2\times10^{-4}$）。
4. **关键物理发现**：小相腔内有势垒（$V_{\max}/V_{\rm wall}\approx8$–$20$），$\ell=1,2$ 是**真共振**（$\vert\Omega_I\vert/\Omega_R=0.0078,\ 9.8\times10^{-5}$）；大相**无势垒**，全部**过阻尼**（$\vert\Omega_I\vert>\Omega_R$）。
5. **但预检验否掉了原设想**：过阻尼边界 $x_{\rm cross}$ 在 $\mu=0.05$–$0.20$ 范围内几乎不动（0.6742→0.6745），而自旋分解 $x_b$ 移动 0.050（0.665→0.615）、势垒消失点 $x_V$ 移动 0.009 ⇒ **谱的定性变化由腔的几何控制，不由热力学控制**。而且 $\ell=0$ 与 $\ell=1$ 的交叉点相差很远（0.53 vs 0.674），说明连“普适边界”都不是。
6. **由此重新设计靶子**：改成 **Hawking–Page（黑洞 ↔ 热平直腔）**——两相是**结构不同**的时空（有/无视界），谱从**复 QNM（衰减）**切换为**实 normal modes（不衰减）**，判据是离散的“有没有 $\Omega_I$”，且有解析锚点（$x=8/9$、$\tau=27/8$、$\Delta S=64\pi/81$）。
7. **待办**：薄腔（大相）求解器未收敛（10–20% 散布），需加三项 Frobenius 与 Chebyshev 广义本征值交叉验证；壁 BC 要扫 Dirichlet/Neumann/Robin；最后与 `2606.11297` 的腔内热积公式数值对账。
