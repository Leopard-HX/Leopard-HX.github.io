### Q2. 检查《cavity_replacement_2211_2607 - 副本.md》推导的错误（2026-09-12）

**问题**：检查这篇推导的错误，给出理由和出处。

**解答**：数学推导部分经逐条复核**未发现错误**；问题全部在**引用/编号**层面。

> **核验证据链**：① 工作区内 arXiv 官方 HTML（`arXiv-2607.03749v2/2607.03749v2.html`、`arXiv-2211.03512v2/2211.03512v2.html`）；② 从 vault git 历史（提交 `96b072e`）恢复的 2607 源文件 `v14.tex`（2435 行）；③ 临时重拉的 2211 官方源 `PTR2209.tex`（273 行）；编号与文字均以**官方 PDF**（[`2607.03749v2.pdf`](/notes/文章整理/arXiv-2607.03749v2/2607.03749v2.pdf)、[`2211.03512v2.pdf`](/notes/文章整理/arXiv-2211.03512v2/2211.03512v2.pdf)）复核；数学恒等式用 Wolfram Language 验证。另：副本与原文件内容逐行一致（均 225 行）。

#### 1. 确定的错误（5 处，均为出处/编号）

**(E1) 2607 温度三次方程编号错**（副本第 118、125 行）：文档两处标 "Eq. (8)"，应为 **Eq. (10)**。
- 理由：2607 在压强公式 (7) 与三次方程之间还有两条**编号公式**：F=E−TS、dF=−SdT−PdV，它们占 (8)、(9)。
- 出处：官方 PDF 原文 "…a cubic equation for the horizon radius, r_h³−r_B r_h²+r_B/(4πT)²=0. **(10)**"，同处 PDF 明确 "F = E − T S **(8)**"、"dF = −SdT − P dV **(9)**"；`v14.tex` 行 174–176（F）/178–180（dF）/185–187（`\label{eq:cubic}`）；HTML 元素 `S2.E10` 的编号标签为 "(10)"。文档引第一定律、熵体积时用 (3)、(4)（与 PDF 一致），可知 "(8)" 是与 F 的编号混淆。

**(E2) 2607 结论的节号错**（第 224 行）："Sec. IX 结论行 913–950" → **Sec. V**。
- 理由：2607 全文只有 5 个 section（其后仅附录 A–D）。
- 出处：`v14.tex` 的 `\section` 在行 77（I）/99（II）/311（III）/392（IV）/**913（V = Conclusion）**；HTML 标题 "V Conclusion"。行号 913–950 与"带电黑洞列为推广方向"的内容（行 946–947）本身无误。

**(E3) 2211 的章节范围错**（第 223 行）："Sec. II–V" → 应为 **Sec. II–III**。
- 理由：2211 只有 3 个 section：I Introduction、II Charged AdS black hole、III Summary。
- 出处：`PTR2209.tex` 的 `\section` 在行 44/60/170；HTML 同。

**(E4) 2607 引用范围自相矛盾**（第 224 行）："Eqs. (1)–(8)（度规、第一定律、(S,V,E,T,P) 和温度三次方程）"——所列内容实际是 **(1)–(7) 与 (10)**；"(8)" 是 F=E−TS，不在列。按 PDF 逐项：(1)(2) 度规、(3) 第一定律、(4) S,V、(5) E、(6) T、(7) P、(10) 温度三次方程。

**(E5) 2211 质量公式与原文印刷不一致**（第 11–16 行）：文档写 M=…+**Q²/(2r_h)** 并标注"源码 PTR2209.tex 行 62–76"；但**原文行 63、HTML、官方 PDF 三处都印 Q²/(2r_h²)**。
- 判断：原文该处是**笔误**——与同文式(2)(4)(5)（r_c=√6Q 等）及量纲均不自洽；正确形式即文档所写的 Q²/(2r_h)（Kubiznak–Mann 标准式）。
- 证明（Wolfram）：以 Q²/(2r_h²) 计算 (∂M/∂S)−T_h = Q²(r_h−2)/(4πr_h⁴) ≠ 0；以 Q²/(2r_h) 计算 = 0。
- 建议：保留自洽形式，但加脚注说明"原文印刷为 2r_h²，应为笔误"，否则"按源码引用"的表述与源文件字面不符。

#### 2. 次要瑕疵（行号、措辞）
