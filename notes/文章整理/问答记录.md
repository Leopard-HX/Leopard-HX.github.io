#### 3. 新补的 HTML 全文（6 篇，来源 `https://arxiv.org/html/<编号>`）

各目录下与 PDF 同名的 `.html`（EHT 目录为 `SgrA_EHT_2022.html`）。下载后做了两类路径改写，否则用 `file://` 本地打开会丢样式、图形全裂：

- `src="<编号>/…"` / `data="<编号>/…"`（LaTeXML 图形，SVG 走 `<object data=…>`）→ `https://arxiv.org/html/<编号>/…`
- `="/static/…"`（CSS、图标）→ `https://arxiv.org/static/…`

注意：图形是 **arXiv 在线地址，需联网显示**；离线看公式与图请用 PDF。另外 **M87 那篇（1906.11238）没有 HTML 版**——它 2019 年投稿，早于 arXiv 的 HTML（LaTeXML）服务，ar5iv 也已不再提供该页（现在重定向回 `abs` 页）。

个别论文的 HTML 公式渲染不可靠（根号/分母丢失），已在对应笔记里标注：见 `arXiv-2211.03512v2/总结-电荷AdS黑洞相变速率.md` 第十节。
